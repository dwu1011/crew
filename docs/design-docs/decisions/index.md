# Design decisions

Record significant decisions here when they affect later work. Existing messaging rationale is in the [durable messaging design](../durable-messaging.md); do not duplicate it into a new record solely to fill this directory.

Use a descriptive filename such as `001-project-run-identity.md`. Include status, date, context, decision, alternatives, consequences, and links to the spec, design, implementation, and source material. Supersede prior decisions explicitly rather than silently rewriting their history.
