# Product specs

Specs describe user-visible behavior, constraints, and scope. Design rationale belongs in [design docs](../design-docs/index.md); implementation progress belongs in [execution plans](../exec-plans/index.md).

| [Autonomous feature delivery](autonomous-feature-delivery.md) | Draft for user review: proportional planning, durable tasks, agent groups, scheduling, independent verification, and autonomous release. Not accepted or implemented. |

For new specs, include status, problem, users, intended behavior, acceptance criteria, constraints, and out-of-scope work. Link the implementation plan when one exists.
