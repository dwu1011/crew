# Design docs

Design docs explain Crew's technical choices and their tradeoffs. They connect [product requirements](../product-specs/index.md), code, and [inspiration sources](../references/index.md).

- [Durable messaging](durable-messaging.md): persistence, submission evidence, acknowledgment, and recovery.
- [Decisions](decisions/index.md): significant choices recorded as they are made.
- [Architecture](../../ARCHITECTURE.md): the current implementation map.

For a new design, record status, the problem, chosen approach, alternatives, tradeoffs, and verification. Link to the relevant spec, implementation, and sources. Mark superseded designs explicitly and link their replacement.
